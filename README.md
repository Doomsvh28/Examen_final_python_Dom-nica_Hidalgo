### Pregunta  1
Podríamos definir un algoritmo como un bloque de texto que se crea para un fin específico, en el que se manejan objetos o elementos del código para conseguir un fin o llegar a una decisión, como por ejemplo: tomar la decisión más óptima o buscar un nombre en específico en un índice. Los pasos para resolver un problema de programación serían, primero, analizar el tipo de estructura y la herramienta de organización de información (lista, diccionario, variables, etc.) que tu código necesita de acuerdo a los datos que vas a ingresar o que el usuario va a ingresar y formar tu código de acuerdo a eso. Pienso que esos son los 2 pasos fundamentales para la construcción de cualquier código. 
### Pregunta 2
La principal diferencia entre print() y return es que el primero muestra al usuario un resultado, ya sea una palabra, un número, una operación matemática etc, pero no guarda nada, mientras que el segundo (return) devuelve el valor y lo guarda, a este lo emplearía cuando necesito usar el valor guardado, mientras que al print solo lo usaría para mostrar el resultado, pero no para guardarlo en la memoria de la función.
### Pregunta 3
El scope es el alcance que tiene una variable desde que es definida cuando construimos un código, es decir, qué tanto abarca esa variable en todo el código si está dentro de una función, lista, clase, etc., o si se encuentra fuera de esta. Existen dos tipos, como lo detallaré a continuación:
La diferencia entre una variable local y una global es que la primera no se encuentra definida en el código "total" por así decirlo, es más bien una variable que está indexada o es parte de un subcódigo, mientras que por el otro lado, una variable global es aquella que está definida en el código global y no depende una función o de otros para estar.
### Pregunta 4
Una lista en Python es una forma de organizar código en la que se le asigna un nombre y se dan elementos dentro de corchetes, separados por comas, pueden incluir tanto strings como enteros o decimales, entre otros. A diferencia de una tupla, los elementos no son inmutables y pueden cambiar.
Un ejemplo sería:
memoria = []
for n in memoria:
  memoria.append(n)
print(memoria(32))
